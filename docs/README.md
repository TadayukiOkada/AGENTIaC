# Documentation

This directory holds the documentation for the public **AGENTIaC** core repository. An installation's
machine declarations, generated model tables and operational records live in its site repository.

## Start here

| Reader / question | Read |
|---|---|
| New user: how do I bootstrap the core or create a site? | [Root README](../README.md), [Create your own site](../README.md#create-your-own-site), [Example site](../examples/site/README.md) |
| Developer: how do I run tests, linters and publication checks? | [Development and control setup](development.md) |
| Suite user: how are coding-agent frontends pinned and probed? | [Agent frontend reference](agents.md) |
| Architect: what are the core design rules? | [ADR 0001](adr/0001-small-cluster-control.md), [ADR 0002](adr/0002-evaluation-before-routing.md), [ADR 0005](adr/0005-chatgpt-subscription-alias.md), [ADR 0009](adr/0009-detect-and-propose-apply-by-approval.md) |
| Maintainer: how is documentation kept consistent? | [Documentation maintenance](documentation-guide.md) |

## Authority map

| Category | Canonical scope / location |
|---|---|
| Core CLI, lifecycle, Suite and management API | This repository (`src/agentiac/`, `scripts/`, `infra/`, `gateway/`, `dashboard/`, `benchmarks/`, `runtime/`) |
| Accepted core architecture decisions | [`docs/adr/0001-small-cluster-control.md`](adr/0001-small-cluster-control.md), [`docs/adr/0002-evaluation-before-routing.md`](adr/0002-evaluation-before-routing.md), [`docs/adr/0005-chatgpt-subscription-alias.md`](adr/0005-chatgpt-subscription-alias.md), [`docs/adr/0009-detect-and-propose-apply-by-approval.md`](adr/0009-detect-and-propose-apply-by-approval.md) |
| Minimal valid site contract | [`examples/site/`](../examples/site/README.md), validated in CI by `make example-check` |
| One installation's hosts, pins, routes and retention ledger | The site repository (`infra/inventory.yml`, `infra/components.yml`, `infra/retention.yml`, `gateway/`, `backends/`, `profiles/`, `agents/`, `evidence/`) |
| Generated model bindings and compatibility tables | The site repository (`docs/model-names.md` and `docs/compatibility.md`, generated by `agentiac model names --write` and `agentiac model compatibility --write`) |
| Runtime state, secrets and evaluation traces | The site repository's ignored `secrets/`, `artifacts/` and `private/` directories |

No document overrides explicit owner decisions or repository safety instructions. Source code proves what is
implemented, not that an unmet requirement has been waived. A declared pin is not proof of a running process.
See [maintenance rules](documentation-guide.md) for how this collection is maintained.
